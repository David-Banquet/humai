Lexique · les mots du dossier

Lexique

Les mots techniques du dossier, expliqués pour qui ne lit pas de code. Dans les modules, ils sont soulignés en pointillés : la définition s'affiche au survol, ou au toucher sur téléphone.

advisorModel
Un réglage de Claude Code : un second modèle, plus fort, que l'agent consulte pour avis avant de s'engager et avant de rendre son travail.
Agent
Un programme d'IA qui ne se contente pas de répondre : il agit seul, sur plusieurs étapes (lire du code, lancer des commandes, écrire et tester), jusqu'à l'objectif qu'on lui a donné.
Application TypeScript
TypeScript est un langage de programmation très utilisé pour les applications web ; l'application de Wavo est écrite avec.
AskUserQuestion
L'outil de Claude Code qui pose une question à l'humain sous forme de formulaire : quelques options, et on répond d'un clic.
Atrophie
Le déclin d'une capacité qu'on n'exerce plus, comme un muscle qu'on ne fait plus travailler.
-auto
Une option de la commande @Odette : l'agent va seul jusqu'à la PR.
AWS
Amazon Web Services : le cloud d'Amazon, qui loue serveurs, bases de données et services à la demande.
Backlog
La liste des tâches créées, mais pas encore démarrées.
Bot
Un programme qui poste des messages tout seul, par exemple les alertes.
Brain rot
« Pourrissement du cerveau » : le mot de l'année 2024 du dictionnaire d'Oxford, pour l'abrutissement attribué au défilement sans fin des contenus en ligne.
Branche
Une copie de travail du code, à côté de la version principale, où l'on prépare une modification sans gêner les autres. Elle revient dans la version principale par une PR.
Buffer
Une file d'attente : ici, les tâches en cours qui attendent d'être reprises.
bug-fix
La commande @Odette pour un bug : la tâche est créée, et un agent prépare le correctif.
Burn-out
Un épuisement professionnel, physique et mental, causé par une surcharge qui dure.
Canal
Dans Slack, un espace de discussion consacré à un sujet.
Cas limite
Une situation rare, en bordure de ce qui était prévu, qu'aucun test n'avait couverte.
Cause racine
La cause première d'une panne, celle qui, corrigée, l'empêche de revenir, par opposition à ses symptômes.
CD
Déploiement continu : après le merge, la modification part automatiquement en production.
Charge cognitive
L'effort mental que demande une tâche. L'attention disponible est limitée : ce qui la consomme pour rien en retire à ce qui compte.
Chat
Une conversation écrite avec une IA, question après réponse, comme dans une messagerie.
Checks
Les vérifications automatiques qui tournent sur une PR (tests, analyses de sécurité) ; chacune passe au vert ou au rouge.
CI
Intégration continue : à chaque PR, une batterie de vérifications automatiques tourne et peut bloquer le merge.
Claude
L'IA conçue par la société Anthropic.
Claude Code
La version de Claude qui travaille directement dans le code d'un projet : elle lit les fichiers, lance des commandes et écrit le code, depuis le terminal du développeur.
Claude Tag
Claude dans Slack : on le mentionne dans un message, et il lance une session pour traiter la demande.
Cloud
Des serveurs et des services loués à la demande chez un hébergeur, au lieu de machines à soi.
Commit
Un enregistrement d'une étape de modification du code, avec un message qui la décrit. Une branche est une suite de commits.
Contrôle déterministe
Une vérification faite par un programme fixe, qui donne toujours la même réponse pour la même situation, sans IA.
Critères d'acceptation
Les conditions vérifiables qui disent qu'une tâche est finie.
Cron
Un réglage qui lance un programme tout seul à cadence fixe : chaque jour à 9 h, chaque lundi.
D2
Un langage pour décrire un schéma en texte ; un outil le dessine ensuite.
Data platform
La plateforme de données : elle récupère les données des clients (ventes, stocks, banque), les nettoie et les met à disposition de l'application.
Dépendances
Les briques de code écrites par d'autres, que le projet réutilise. Une faille dans l'une d'elles devient une faille du projet.
Déploiement
Le moment où une modification arrive dans la version qu'utilisent réellement les clients.
Dépôt
L'endroit où vivent le code d'un projet et tout son historique, ici sur GitHub.
Détections de sécurité
Les alertes levées par les services de sécurité d'AWS quand ils repèrent un comportement suspect : un accès inhabituel, un port ouvert, une configuration risquée.
Dette cognitive
L'effort de réflexion qu'on s'est épargné en le déléguant à une IA, et qu'on finit par payer : on comprend et on retient moins ce qu'on a produit.
Dev
Selon le contexte : un développeur, ou l'environnement de développement, une copie séparée où l'on teste sans toucher aux clients.
DynamoDB
Une base de données d'AWS ; ici, elle sert de verrou partagé entre les sessions.
ECS
Un service d'AWS qui fait tourner des programmes en continu.
Fable
Le modèle de Claude le plus puissant, plus cher par appel : ici, il conseille plutôt qu'il n'exécute.
Feature
Une fonctionnalité, ou un chantier : un ensemble de tâches qui apportent ensemble une même valeur à l'utilisateur.
Fil
Sous un message Slack, la suite de réponses qui en discutent, sans encombrer le canal.
Forge
Le service qui héberge le code et ses PR, comme GitHub.
gh
L'outil en ligne de commande de GitHub : il permet à un script ou à un agent d'interroger GitHub.
GitHub
Le service en ligne qui héberge le code et ses PR, et sur lequel tournent les vérifications automatiques.
github-pr
Le skill qui ouvre une PR, puis la suit : vérifications, relecture, corrections, merge et déploiement.
handoff-session
Un skill qui confie une session locale à une machine jetable, avec une note de passation : l'objectif, les décisions, ce qui est fait et ce qui reste.
Hook
Un petit programme qui se déclenche tout seul à un moment précis de la vie de l'agent, par exemple quand il veut s'arrêter, pour vérifier ou bloquer quelque chose.
Hook de type agent
Un hook qui, au lieu d'un script fixe, confie la vérification à un modèle : il va regarder l'état réel et juge si l'objectif est atteint.
Hook Stop
Le hook qui se déclenche quand l'agent veut rendre la main : il peut le renvoyer au travail si l'objectif n'est pas atteint.
Intégration
Le branchement de Wavo sur un logiciel du client (gestion, comptabilité, banque) pour en lire les données.
Issue
Un ticket qui signale un bug ou demande une évolution, sur GitHub ou dans Sentry.
Job
Un traitement automatique qui tourne seul, par exemple chaque nuit, pour récupérer ou transformer des données.
job-story
Une manière d'écrire un besoin : « quand..., je veux..., pour... ». Taguer @Odette job-story dans un fil Slack en fait une tâche.
Ligne Goal:
La dernière ligne d'une demande, qui décrit l'état à atteindre, par exemple « la PR existe et est liée à la tâche ». Un contrôle vérifie cet état avant de laisser l'agent s'arrêter.
Log
Le journal qu'écrit un programme pendant qu'il tourne : ce qu'il fait, et ses erreurs.
/loop
Une commande de Claude Code qui fait tourner une même tâche en continu, par exemple pour suivre une PR jusqu'au bout.
Machine jetable
Une machine créée pour une seule session puis détruite : ce que l'agent y casse ne touche rien d'autre.
MCP
Model Context Protocol : un standard qui permet à une IA d'utiliser un outil extérieur, ici notre outil de pilotage, comme s'il faisait partie d'elle.
Merge
Intégrer une PR relue dans la version principale du code. Après le merge, la modification part vers la production.
Méta-boucle
La boucle qui améliore les autres boucles : ce qui frotte dans le travail des agents devient une règle ou un outil, puis on mesure si ça va mieux.
MicroVM
Une petite machine virtuelle, créée en quelques instants et jetée après usage : l'agent y travaille isolé du reste.
Migration de schéma
Un changement de la structure d'une base de données, comme ajouter une colonne, à appliquer sans perdre ni casser les données.
MIT Media Lab
Un laboratoire de recherche du MIT, l'université américaine, qui étudie les usages des technologies.
Modèle
Le moteur d'une IA : un programme entraîné sur d'immenses quantités de texte, qui produit la suite la plus probable d'une conversation. Opus et Fable sont des modèles de Claude.
Monitor
Un outil de Claude Code qui surveille un flux d'événements et réveille l'agent à chacun, au lieu de le faire vérifier à intervalle fixe.
Odette
Notre outil interne de pilotage : on y écrit les features, les plans et les tâches, et on peut l'appeler depuis Slack.
odette-split-plan
Le skill qui découpe le plan validé d'une feature en tâches, toutes au même gabarit.
odette-start-task
Le skill qui démarre une tâche : il la crée sous sa feature, crée sa branche et ouvre un workspace avec un agent qui connaît déjà la tâche.
Onboarding
L'installation d'un nouveau client : paramétrage, branchement de ses outils, premiers imports de données.
Opus
Un modèle de Claude, rapide et capable, qui fait ici le gros du travail.
Orchestrateur
Le programme qui reçoit les demandes et lance les sessions d'agents.
Pare-feu
Un filtre placé devant l'application, qui bloque le trafic suspect avant qu'il l'atteigne.
Port
Une porte d'entrée réseau d'une machine. Un port resté ouvert sur internet peut laisser entrer n'importe qui.
Post-merge
Ce qui se fait après le merge d'une PR : une migration à lancer, une vérification en production.
PR
Pull request : une proposition de modification du code, présentée pour relecture avant d'être intégrée. On la relit, on en discute, puis on la merge.
PR draft
Une PR en brouillon : visible de tous, mais signalée comme pas encore prête à être mergée.
PRD
Product Requirements Document : le document qui décrit ce qu'un produit ou une fonctionnalité doit faire, et pourquoi.
prd-interview
Un skill qui spécifie une fonctionnalité en interrogeant l'humain, une question à la fois, puis rédige le document de spécification (le PRD).
Production
La version en service, celle qu'utilisent les clients, par opposition aux copies de test.
Prompt
Le texte de consigne donné à une IA.
Python
Un langage de programmation très utilisé pour traiter des données ; la data platform de Wavo est écrite avec.
Redrive
Relancer une exécution qui a échoué, à partir de l'étape en échec.
resume-session
Un skill qui rouvre sur l'ordinateur d'un humain une session commencée sur une machine jetable, pour reprendre la main.
Revue
La relecture d'une PR, par un humain ou par un agent, avant le merge.
Routine
Une session d'agent planifiée à cadence fixe, avec une consigne écrite une fois.
Scanner
Un outil qui analyse automatiquement le code ou ses dépendances à la recherche de failles connues.
Scopée
Limitée à un périmètre précis, écrit à l'avance : ce que la tâche couvre, et ce qu'elle ne couvre pas.
Script
Un petit programme qui enchaîne des commandes pour automatiser un geste.
Secret
Un mot de passe ou une clé d'accès que le code utilise, et qui ne doit jamais apparaître en clair.
Sentry
Un service qui collecte les erreurs du code en production et les regroupe en issues.
Serverless
Sans serveur à gérer soi-même : le code tourne à la demande chez un hébergeur, ici AWS, qui s'occupe des machines.
Session
Une conversation de travail avec un agent : il reçoit une demande, travaille, et garde en mémoire ce qui s'y est dit jusqu'à la fin.
Skill
Une procédure écrite une fois, que l'agent réutilise : les étapes, les règles et les outils d'une tâche précise, comme ouvrir une PR ou découper un plan.
Slack
La messagerie de l'équipe : des canaux par sujet, et des fils de discussion sous chaque message.
Superset
L'application qui ouvre un workspace par tâche et montre d'un coup d'œil toutes les sessions d'agents en cours.
TALA
Le moteur de mise en page qui place les boîtes et les flèches d'un schéma D2.
Thread
Le mot anglais pour un fil de discussion dans Slack.
Transcript
L'enregistrement complet d'une session : tout ce que l'agent a lu, fait et répondu.
Transformer
L'architecture de réseau de neurones, publiée par Google en 2017, sur laquelle reposent les modèles de langage actuels.
Verrou
Un mécanisme qui garantit qu'une seule session à la fois prend une décision donnée, pour éviter les doublons.
Workflow
Un enchaînement d'étapes automatiques, lancé par un événement ou à heure fixe.
Workspace
Un dossier de travail isolé, avec sa propre branche, où un agent avance sans marcher sur les autres.
